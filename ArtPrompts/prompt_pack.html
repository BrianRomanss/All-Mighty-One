Hub Prompt Pack

One master mockup of the hub sets the look. Every asset after it attaches that mockup, so the logo, the twelve game icons and the background all come out as one family.

How it works

  1. Phase 1: the master screen. mock_hub attaches a screenshot of the real hub (hub_current.png) and redraws it as a finished, polished screen with the same layout. Re-roll it until you love it.
  2. Phase 2: assets. Every card names the images to attach (the orange chips). Game icons also attach a screenshot of that game (thumb_<game>.png), so Gemini draws the right game in the hub's style.
  3. The tool does the clicking. python ArtPrompts/gemini_gen.py gen todo runs every prompt in the Gemini window, attaching the references for you, and saves candidates in ArtPrompts/out/. keep picks one, fix sends a follow-up change.
  4. Cut-out goes straight into the hub. python ArtPrompts/cutout.py crops and cleans the kept images into Assets/_Collection/Art/Hub; rebuilding the hub picks them up.
Negative prompt (if your generator has one):
Text in the mockup is fine. It needs labels to read as real UI; the game draws its own text, so misspellings don't matter there. Icons, the background and the store graphics have no text.
